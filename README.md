This repository contains the complete raw data and calculation workbook for the **LLM_code_assessment** project, which investigates the performance of large language models (LLMs) in automated code quality evaluation. The data covers **two assessment channels** – a self‑developed system (with controllable parameters) and a third‑party platform (workbuddy) – across **36 students** over **5 rounds** of programming tasks, with detailed scores in four dimensions (Basic Quality, Maintainability, Performance Efficiency, and Security).
